# Standing rules for this repo

- **Static site on GitHub Pages**: plain HTML, CSS, JS. No frameworks. Python scripts live in `/scripts`.
- **Design**: Times New Roman, palette beige, white, navy, coral. Match existing styles in `map.html` and `india.html`.
- **British English** in all UI text.
- **Canonical seat IDs**: House `"AZ-01"`, Senate `"Senate-TX"`, Governor `"Gov-TX"`.
- `assets/briefs.json` is generated by `scripts/build_briefs.py`. Never hand-edit it.
- `briefs-src/` is private source material. Never commit it.
- Work only on the current feature branch. Summarise changed files before every commit.
